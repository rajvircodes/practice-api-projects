# Joke Teller (Frontend-Backend Connection)

A minimal full-stack application demonstrating how to connect a frontend user interface to a backend Express API using CORS and Fetch.

## Features

- Full-Stack Integration: Connects a static frontend to a local Node.js API.

- CORS Enabled: Configured cross-origin - resource sharing to allow seamless communication.

- Dynamic Content: Serves random jokes to the frontend on demand.
